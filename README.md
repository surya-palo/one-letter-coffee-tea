## The entry

Exactly one letter, and nothing else: **A** — coffee.

`main.py` (Python standard library only) writes the single letter `A` to
`/output/entry.txt`. No word, no explanation, no punctuation, no trailing
newline — the gate requires UTF-8 text of exactly 1 character.

## Why A (coffee)

See [BUILD_LOG.md](BUILD_LOG.md) for the reasoning. In short: judged on
vividness first, coffee is the louder, bolder, more alive answer — dark,
bitter, and defended with real passion — while tea reads gentler and more
restrained. A single letter has to carry the whole stance, and coffee
carries more of it.

## Run

```sh
python3 main.py
```

Then `/output/entry.txt` holds exactly one byte: `A`.
